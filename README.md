# Open Arc

A community, clean-room effort to preserve the Arc browser workflow after Arc's sunset, so anyone can keep using it locally and for free.

| Part | What it is | Status |
|------|-----------|--------|
| [`spec/`](spec/) | Behavioral spec of Arc's features + documented on-disk data formats | 📝 drafts |
| [`exporter/`](exporter/) | `arc-export`: get your Spaces, pinned tabs, Favorites and Archive out of Arc | ✅ v0.1 |
| [`browser/`](browser/) | A new, independent, Arc-style browser built from the spec | planned |

## Not affiliated
Open Arc is not affiliated with, endorsed by, or connected to The Browser Company or Atlassian. "Arc" is used only to describe compatibility. This repo contains **no Arc source code, binaries, decompiled code, icons, sounds, or other assets**. See [CLEANROOM.md](CLEANROOM.md) for how the project keeps it that way.
